10. 결론

6주차 실습에서는 HTML의 기본 태그와 CSS의 핵심 속성을 직접 입력하고 실행 결과를 확인하였다. 제목과 본문 태그로 글자의 위계를 표현하고, 앵커 태그로 다른 페이지를 연결하였으며, ul과 ol 태그를 바꾸는 것만으로 목록의 형태가 달라지는 것을 확인하였다. 표에서는 colspan과 rowspan으로 칸을 합치는 방법을 익혔다. CSS에서는 전체·태그·아이디·클래스 선택자의 차이를 비교하였고, width·height·margin·padding·border로 이루어진 박스 모델과 display, position, z-index 속성으로 요소의 배치와 쌓이는 순서를 조절해 보았다.

실습 중 몇 가지 문제를 겪었다. 미션5-1에서는 이미지 주소가 실제 이미지 파일이 아니어서 그림 대신 alt 문구만 표시되었고, 미션5-2에서 올바른 이미지 주소로 바꾸자 펭귄 이미지가 정상적으로 나타났다. 이를 통해 img 태그의 src가 유효해야 이미지가 표시되며, alt 속성은 이미지가 없을 때 대신 보이는 설명이라는 것을 알게 되었다. 또한 모든 실습 코드를 GitHub에 한 파일로 올렸을 때 뒤쪽 미션의 CSS가 앞 미션 화면까지 바꾸는 문제가 생겼다. CSS는 같은 문서 전체에 적용되기 때문이었고, AI 도구의 도움을 받아 iframe으로 미션마다 실행 공간을 분리하여 각 실습의 결과를 따로 확인할 수 있도록 정리하였다.

내가 입력한 텍스트로 된 코드가 웹 화면으로 그대로 구현된다는 점이 신기했다. 앞으로는 이번에 배운 선택자와 박스 모델, 위치 속성을 활용해 직접 레이아웃을 구성한 웹페이지를 만들어 보고 싶다.
